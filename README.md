# קורות

תוכנה שמכינה מסמך קורות חיים נקי: בעברית או באנגלית, בפונט David או Arial, כקובץ PDF או Word.

ממלאים פרטים אישיים, תמצית, ניסיון, השכלה, שירות צבאי או לאומי, כישורים ושפות. המסמך נבנה בתצוגה בזמן הכתיבה, והסעיפים מסודרים מהמאוחר למוקדם. אם יש תואר אקדמי, לימודי התיכון לא נכנסים למסמך.

התמצית המקצועית לא חובה. אפשר לכתוב נקודות, ולקצר אותן ל־3–4 שורות. הקיצור מוריד מילים חוזרות, ולא מוסיף עובדות.

מעבר לאנגלית מתרגם את מה שנכתב בעברית. חזרה לעברית מחזירה את הנוסח המקורי. בשירות אפשר לסמן שירות צבאי או שירות לאומי.

הטיוטה נשמרת בדפדפן. השרת מרכיב את הקובץ ולא שומר אותו.

## הרצה

```bash
npm install
npm run dev
```

ואז לפתוח [http://127.0.0.1:3847](http://127.0.0.1:3847).

PDF נוצר בעזרת Chrome המותקן במחשב. אם הוא נמצא במקום אחר, מגדירים `CHROME_PATH`. קובץ Word נוצר גם בלי Chrome, ובתוכו שמות הפונטים הם David או Arial. ב־PDF נטענות המקבילות הפתוחות David Libre ו־Arimo, כדי שהעברית תיראה נכון גם בלי הפונטים של Windows.

```bash
npm test
npm run lint
```
